ROM export status

Raw ROM export is intentionally disabled in this prototype. Writing a valid SMW ROM requires correctly updating level pointers, compressed streams, free-space allocation and checksums. We will enable it only after those parts are implemented and tested.

Implementation roadmap
  1. Local ROM loading and file validation
  2. Header detection and LoROM address helper
  3. Original, independent editor shell
  4. SMW level pointer table reader
  5. Level stream decompressor and object parser
  6. Vanilla graphics extraction and rendering
  7. Safe object editing and recompression
  8. Free-space allocation, pointer updates and ROM export
